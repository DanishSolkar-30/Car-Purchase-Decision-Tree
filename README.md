# 🚗 Car Purchase Prediction Using Decision Tree

A Machine Learning project that predicts whether a customer is likely to purchase a car using the **Decision Tree Classification** algorithm. The model analyzes customer attributes such as Age, Gender, Annual Income, Marital Status, Driving License Status, and House Ownership to make predictions.

---

## 📌 Project Overview

This project demonstrates the implementation of a **Decision Tree Classifier** using Scikit-learn. It includes data preprocessing, model training, evaluation, visualization, and real-time prediction based on user input.

The model learns patterns from historical customer data and predicts whether a new customer is likely to buy a car.

---

## 🎯 Features

- Data preprocessing using Label Encoding
- Decision Tree Classification
- Train-Test Split
- Model evaluation using Accuracy Score
- Confusion Matrix
- Classification Report
- Interactive user input for prediction
- Decision Tree visualization

## 📊 Dataset Features

The dataset contains the following columns:

| Feature | Description |
|----------|-------------|
| Age | Customer's age |
| Gender | Male/Female |
| Annual_Income | Annual income of the customer |
| Marital_Status | Married/Single |
| Has_Driving_License | Whether the customer has a driving license |
| Owns_House | Whether the customer owns a house |
| Buy_Car | Target variable (Yes/No) |

---

## ⚙️ How It Works

1. Load the dataset.
2. Convert categorical values into numerical values using Label Encoding.
3. Select input and target variables.
4. Split the dataset into training and testing sets.
5. Train the Decision Tree Classifier.
6. Evaluate the model using:
   - Accuracy Score
   - Confusion Matrix
   - Classification Report
7. Accept customer details from the user.
8. Predict whether the customer is likely to purchase a car.
9. Display the Decision Tree visualization.
